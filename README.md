## 🚀 What I bring to a platform team

### Observability & telemetry

- Design federated **Prometheus** architectures with recording rules, **Alertmanager**, and **VictoriaMetrics** for long-term metrics storage.
- Build **Grafana** dashboards that help teams explore service, infrastructure, and network health.
- Develop custom Prometheus exporters and work with **Node Exporter**, **cAdvisor**, and **NGINX Exporter**.
- Build log and metric routing pipelines with **Cribl Edge** and **Cribl Stream**.
- Work with **OpenTelemetry** and **ThousandEyes** for application, web, and network visibility.
- Monitor network devices and application delivery controllers using tools and protocols including **SNMP** and **Telegraf**.

### Cloud, containers & delivery

- Automate infrastructure provisioning and configuration with **Terraform** and **Ansible**.
- Containerize applications and deploy workloads to **Docker**, **Kubernetes**, and **Azure Kubernetes Service (AKS)** environments.
- Build and maintain **Azure DevOps** pipelines for application delivery, container images, and security checks.
- Work with **Azure IaaS/PaaS**, **Azure Container Registry**, and CI/CD tooling including **Jenkins**, **GitHub Actions**, and **GitLab**.

### ServiceNow & operational automation

- Develop **ServiceNow applications**, **Scripted REST APIs**, and **Business Rules**.
- Integrate ITSM workflows with automation tools and scripts.
- Build alerting workflows with **knowledge-base integration** to support incident response.
- Work with **Change Management** processes for controlled operational changes.
- Automate administrative and infrastructure tasks with **Python**, **PowerShell**, and **Shell**.

### DevSecOps

- Integrate security checks into CI/CD workflows using **Black Duck**, **FossID**, and **SonarCloud**.
- Work with **SAST**, **DAST**, and **software composition analysis (SCA)** practices.
- Develop Python automation for open-source license and vulnerability scanning workflows.
